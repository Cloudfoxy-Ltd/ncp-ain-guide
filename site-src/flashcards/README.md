# NCP-AIN flashcard deck

`ncp-ain-flashcards.csv` has three columns: `front`, `back` and `chapter`. All fields are quoted, UTF-8 encoded.

## Import into Anki
1. Download the CSV (open it, then choose **Download raw file**).
2. In Anki: **File → Import**, choose the file.
3. Set **Field separator: Comma**, leave **Allow HTML in fields** unticked, and map field 1 → Front, field 2 → Back, field 3 → Tags.
4. Choose or create a deck called *NCP-AIN* and click **Import**.

## Import into Quizlet
Create a new set, choose **Import**, paste the first two columns and set the separator between term and definition to **comma**.
