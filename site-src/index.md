## Errata and updates

NVIDIA ships new software releases several times a year, so some commands will change after publication. The **[errata page](errata.md)** lists confirmed corrections by edition, chapter and page.

Found an error? **[Report it here](https://github.com/Cloudfoxy-Ltd/ncp-ain-guide/issues/new?template=erratum.yml)**. You'll need a free GitHub account. Include the edition, the page and what you expected to see.

## About the book

The book is **[available now on Leanpub](https://leanpub.com/nvidiancp-aincertificationguide)** (ebook), on [Kindle](https://www.amazon.co.uk/dp/B0HLMP7R9Q) and in paperback on Amazon ([Volume I](https://www.amazon.co.uk/dp/1065446403), [Volume II](https://amzn.eu/d/07kTB52M)). It covers every objective in NVIDIA's published NCP-AIN exam blueprint. It follows one running example, the Helix AI Factory, from start to finish. Each chapter has technical diagrams, a hands-on lab, a troubleshooting scenario and about 40 exam-style questions with explanations. It ends with three 75-question mock exams, a cram sheet, a command reference and a glossary.
